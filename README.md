# Task 28 — Simple Percentage Analysis

## Objective
Calculate each category's contribution to total sales and show the result in a percentage table and chart.

## Dataset
This task uses the standard Sample Superstore category sales totals:
- Furniture: $741,999.80
- Office Supplies: $719,047.03
- Technology: $836,154.03

Total sales (denominator): $2,297,200.86.

## Formula
Contribution Percentage = (Category Sales / Total Sales) × 100

In the Excel workbook, the percentage cells use formulas rather than hard-coded percentages. The total row checks that the category percentages add up to 100%.

## Deliverables
- `Task28_Simple_Percentage_Analysis.xlsx` — formatted percentage table, formula checks, column chart and pie chart.
- `percentage_table.csv` — static percentage table for quick viewing or reuse.

## How to use
1. Open the Excel workbook.
2. Review the `Percentage Analysis` sheet.
3. The denominator is the total sales in cell B8, clearly identified in the sheet.
4. Confirm that the total contribution is 100%.
5. If you update category sales, the percentages and charts update from the formulas.

## Expected approximate contribution
- Furniture: 32.30%
- Office Supplies: 31.30%
- Technology: 36.40%

Note: Sales totals are rounded for display; the workbook keeps the underlying values for calculation.
